Functional prototype. Apollo live usage subject to account credits; models need retraining on real outcomes before production scoring claims 
Business Summary
The AI SDR platform converts a target customer definition into real prospect discovery, evidence-backed enrichment, prioritized qualification, approved outreach, reply handling, follow-up, meeting booking, CRM handoff, and analytics.
1. Business Objective
	•	Reduce manual SDR research by turning ICP criteria into ranked, outreach-ready prospects.
	•	Improve prioritization with ML-based intent, reply, meeting, and qualification probabilities.
	•	Keep outreach controlled through approval gates, suppression logic, and provider event tracking.
	•	Create a feedback loop from replies, meetings, and CRM outcomes back into scoring and ranking.
2. Operating Flow
ICP Setup -> Apollo Prospect Discovery -> Enrichment -> Prospect Intelligence -> Qualification -> Outreach -> Conversation + Follow-Up -> Meeting + CRM -> Analytics

4. Apollo.io Role
Apollo is the primary production discovery source.
Set SDR_DISCOVERY_PROVIDER=apollo_api for real account and people discovery. If Apollo returns 403, the API key or plan does not have access to the Organization Search endpoint; the application cannot bypass that provider restriction.
Apollo serves as the primary external organization discovery and enrichment provider for the AI SDR platform.
The platform uses Apollo Organization Search to identify organizations that match the configured Ideal Customer Profile (ICP). Returned organizations are mapped into the platform's internal DiscoveredAccount model before progressing through enrichment, intelligence, qualification, and outreach workflows.
Apollo Organization Enrichment provides additional business intelligence including employee estimates, annual revenue, technology stack information, company descriptions, and other firmographic attributes used to improve account qualification and personalization.
Current capabilities
	•	Apollo Organization Search for organization discovery.
	•	Organization enrichment using Apollo company data.
	•	Mapping of Apollo organizations into the internal discovery model.
	•	Integration with Prospect Intelligence for account prioritization.
	•	Streamlit and FastAPI integration.
	•	Runtime provider switching between Mock, Public, and Apollo providers.
Current limitation
	•	Live organization discovery depends on available Apollo lead credits.
	•	When Apollo credits are exhausted, the provider returns HTTP 422 (Insufficient Credits).
	•	This is an Apollo account limitation rather than an application limitation.

6. Demo and Production Notes
	•	Apollo Organization Search is the preferred production discovery provider.
	•	Organization Enrichment improves account qualification using verified firmographic and technographic information.
	•	Public providers and Mock mode remain available for development, testing, and demonstrations.
	•	Live organization discovery requires available Apollo lead credits.
	•	Prospect Intelligence uses enriched organization data to improve account ranking and personalization.
	•	The platform supports seamless switching between provider modes through configuration
	•	Apollo-only mode is best for proving real prospect discovery if the API plan supports Organization Search.
	•	SearXNG/OpenSearch remains important for enrichment because it gathers public evidence and links.
	•	MetaRank improves ranking only after enough outreach outcome events are collected.
	•	Temporal is used for durable follow-up, sequence, and meeting reminder workflows.
7. Marketplace and Shopify
	•	The store backend is now a multi-seller marketplace. The SDR platform is the merchant acquisition channel: ICP, discovery, outreach and meeting handoff end with the merchant applying as a seller.
	•	Sellers connect a Shopify store, import their catalog, and stay in sync through signed webhooks and stock push-back.
	•	Admins approve or suspend sellers from the Admin Sellers tab.
	•	Not yet available: seller-created products without Shopify, per-seller order splitting and payouts, Shopify OAuth install, automated CRM-to-seller invitation.
